### 2. เครื่องมือ AI ที่ใช้:

### 3. งานส่วนไหนใช้ AI:

- [ ] Requirement Analysis
- [x] Database Design - ส่วน: ช่วยทำความเข้าใจโครงสร้างฐานข้อมูล ความสัมพันธ์ระหว่างตาราง และการทำงานของข้อมูลที่เกี่ยวข้องกับเมนูและออเดอร์
- [x] System Architecture - ส่วน: ช่วยอธิบายโครงสร้าง Backend, API Endpoints และการเชื่อมต่อระหว่าง Controller, Model และฐานข้อมูล
- [ ] Document/Grammar Check
- [x] อื่นๆ: ช่วยอธิบายโค้ด Backend ตรวจสอบข้อผิดพลาด และแนะนำแนวทางแก้ไขปัญหาระหว่างการพัฒนา

### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ช่วยอธิบายการทำงานของโค้ด Backend ในระบบ Cafe POS และตรวจสอบว่าการทำงานของ API สอดคล้องกับโครงสร้างฐานข้อมูลหรือไม่ พร้อมแนะนำแนวทางแก้ไขข้อผิดพลาดที่พบ"

"ช่วยอธิบายขั้นตอนการทำงานของ API สำหรับจัดการเมนูและสร้างออเดอร์ รวมถึงตรวจสอบการรับส่งข้อมูลระหว่าง Controller, Model และ MySQL"

### 5. ผลลัพธ์จาก AI:

AI ช่วยอธิบายการทำงานของ Backend และ API รวมถึงให้คำแนะนำเกี่ยวกับการจัดการข้อมูลเมนูและออเดอร์ การเชื่อมต่อฐานข้อมูล และแนวทางตรวจสอบข้อผิดพลาด เพื่อช่วยให้เข้าใจขั้นตอนการพัฒนาและตรวจสอบความถูกต้องของระบบได้ดียิ่งขึ้น

### 6. การปรับแต่งของตัวเอง:

นำคำแนะนำจาก AI มาศึกษาและตรวจสอบกับโค้ดและโครงสร้างฐานข้อมูลของโปรเจกต์ จากนั้นพิจารณาความเหมาะสมและปรับแก้ให้สอดคล้องกับ Requirement, Business Rule และ Sequence Diagram ของกลุ่ม พร้อมตรวจสอบผลการทำงานก่อนนำไปใช้

### 7. เหตุผลในการใช้ AI:

เพื่อช่วยทำความเข้าใจโครงสร้าง Backend และการทำงานของ API ลดเวลาในการค้นหาสาเหตุของข้อผิดพลาด และใช้เป็นแนวทางในการพัฒนาและตรวจสอบระบบ โดยผู้จัดทำยังคงต้องตรวจสอบความถูกต้องและรับผิดชอบโค้ดที่ส่ง

### 8. Diagram/เอกสารต้นทางของ Sprint นี้:

- `wk03-requirements.md` — ข้อกำหนดความต้องการของระบบ
- `wk04-user-stories.md` — User Stories และ Acceptance Criteria
- Use Case Diagram ของกลุ่ม
- Business Rule และ Sequence Diagram จากสัปดาห์ที่ 9

### 9. ส่วนที่ AI ช่วยเขียนโค้ด:

- โค้ด Backend ที่เกี่ยวข้องกับ API สำหรับจัดการเมนูและสร้างออเดอร์ เฉพาะส่วนที่มีการใช้ AI ช่วยจริง
- คำแนะนำเกี่ยวกับการเชื่อมต่อฐานข้อมูลและการตรวจสอบข้อผิดพลาดในโค้ด

### 10. สมาชิกที่อธิบายโค้ดส่วนนี้ได้ (ต้องมีอย่างน้อย 1 คนต่อส่วน):

สมาชิกที่รับผิดชอบโค้ดแต่ละส่วนเป็นผู้ทบทวนและทำความเข้าใจการทำงานของ API, Backend และฐานข้อมูล เพื่อให้สามารถอธิบายส่วนที่ตนเองรับผิดชอบได้
