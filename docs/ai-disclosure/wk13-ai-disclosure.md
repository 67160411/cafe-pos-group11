- [ ] ไม่ได้ใช้ AI
- [x] ใช้ AI (กรุณาระบุรายละเอียด)

### 2. เครื่องมือ AI ที่ใช้:

- ChatGPT

### 3. งานส่วนไหนใช้ AI:

- [ ] Requirement Analysis
- [x] Database Design - ส่วน: ช่วยทำความเข้าใจโครงสร้างฐานข้อมูล ความสัมพันธ์ระหว่างตาราง และการตรวจสอบข้อมูลที่ใช้ในการทำงานร่วมกันของแต่ละ Module
- [x] System Architecture - ส่วน: ช่วยอธิบายการทำงานร่วมกันของ Backend, API Endpoints และ MySQL รวมถึงแนวทางตรวจสอบความสอดคล้องของข้อมูลระหว่าง Module
- [ ] Document/Grammar Check
- [x] อื่นๆ: ช่วยอธิบายโค้ด วิเคราะห์ข้อผิดพลาด และแนะนำแนวทางแก้ไขปัญหาระหว่างการพัฒนาและทดสอบระบบ

### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ช่วยตรวจสอบโค้ด Backend ของ Cafe POS ว่ามีข้อผิดพลาดหรือไม่ และแนะนำวิธีแก้ไข พร้อมอธิบายวิธีตรวจสอบว่าข้อมูลจาก API และฐานข้อมูลสอดคล้องกัน"

"ช่วยแนะนำแนวทางตรวจสอบการทำงานร่วมกันของแต่ละ Module ในระบบ Cafe POS และอธิบายวิธีออกแบบ Test Case เพื่อทดสอบการทำงานของระบบตั้งแต่ต้นจนจบ"

### 5. ผลลัพธ์จาก AI:

AI ช่วยอธิบายการทำงานของโค้ดและการเชื่อมต่อระหว่าง Module รวมถึงเสนอแนวทางตรวจสอบข้อผิดพลาดและทดสอบความถูกต้องของข้อมูลระหว่าง API กับฐานข้อมูล เพื่อใช้เป็นแนวทางในการตรวจสอบและปรับปรุงระบบ

### 6. การปรับแต่งของตัวเอง:

นำคำแนะนำจาก AI มาตรวจสอบกับโค้ดจริงและ Requirement ของกลุ่ม พิจารณาว่าแนวทางที่แนะนำเหมาะสมกับระบบหรือไม่ แล้วจึงปรับใช้และตรวจสอบผลลัพธ์หลังแก้ไข รวมถึงพิจารณาความสอดคล้องระหว่างโค้ด ฐานข้อมูล และ Diagram ที่เกี่ยวข้อง

### 7. เหตุผลในการใช้ AI:

เพื่อช่วยให้เข้าใจการทำงานร่วมกันของ Module และช่วยค้นหาสาเหตุของข้อผิดพลาดระหว่างการพัฒนาและทดสอบ ทำให้สามารถตรวจสอบระบบได้เป็นขั้นตอนและลดเวลาในการแก้ปัญหา โดยผู้จัดทำยังคงเป็นผู้ตรวจสอบผลลัพธ์และรับผิดชอบผลงานที่ส่ง

### 9. ส่วนที่ AI ช่วยเขียนโค้ด:

- คำแนะนำและการแก้ไขโค้ด Backend และ API เฉพาะส่วนที่มีการใช้ AI ช่วยจริง
- คำแนะนำเกี่ยวกับการเชื่อมต่อฐานข้อมูลและการตรวจสอบข้อมูลระหว่าง Module
- แนวทางตรวจสอบข้อผิดพลาดและออกแบบ Test Case สำหรับการทดสอบระบบ

### 10. สมาชิกที่อธิบายโค้ดส่วนนี้ได้ (ต้องมีอย่างน้อย 1 คนต่อส่วน):

สมาชิกที่รับผิดชอบแต่ละส่วนทบทวนและทำความเข้าใจการทำงานของโค้ด Backend, API และฐานข้อมูล รวมถึงสามารถอธิบายวิธีตรวจสอบข้อผิดพลาดและผลการทดสอบของส่วนที่ตนเองรับผิดชอบได้
