# AI Disclosure สำหรับ Coding Sprint ตาม AI-USAGE-POLICY.md

## การใช้ AI ในงานนี้ (AI Usage Declaration)

### 1. ใช้ AI หรือไม่?

- [ ] ไม่ได้ใช้ AI
- [x] ใช้ AI (กรุณาระบุรายละเอียด)

### 2. เครื่องมือ AI ที่ใช้:

- ChatGPT

### 3. งานส่วนไหนใช้ AI:

- [ ] Requirement Analysis
- [ ] Database Design
- [x] System Architecture - ส่วน: ช่วยอธิบาย Flow การทำงานของระบบและความสัมพันธ์ระหว่าง Frontend, Backend, API และฐานข้อมูลที่เกี่ยวข้องกับรายงานยอดขาย
- [ ] Document/Grammar Check
- [x] อื่นๆ: ช่วยทำความเข้าใจและตรวจสอบแนวทางการออกแบบ Sequence Diagram สำหรับ Flow รายงานยอดขายของระบบ Cafe POS

### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ช่วยอธิบายขั้นตอนการทำงานของระบบรายงานยอดขาย Cafe POS ตั้งแต่ผู้ใช้เลือกสาขาและเรียก API จนถึงการดึงข้อมูลจากฐานข้อมูลและแสดงผลรายงาน พร้อมแนะนำองค์ประกอบที่ควรมีใน Sequence Diagram"

"ช่วยตรวจสอบว่า Sequence Diagram ของรายงานยอดขายแสดงลำดับการทำงานระหว่างผู้ใช้ Frontend, API, Backend และฐานข้อมูลได้ครบถ้วนหรือไม่"

### 5. ผลลัพธ์จาก AI:

AI ช่วยอธิบายลำดับการทำงานของ Flow รายงานยอดขาย และให้คำแนะนำเกี่ยวกับการแสดงการสื่อสารระหว่างส่วนต่าง ๆ ของระบบ เพื่อใช้เป็นแนวทางในการออกแบบและตรวจสอบ Sequence Diagram

### 6. การปรับแต่งของตัวเอง:

นำคำแนะนำจาก AI มาพิจารณาและปรับให้สอดคล้องกับ Requirement, โครงสร้างระบบ และการออกแบบของกลุ่ม โดยตรวจสอบลำดับการทำงานและความสัมพันธ์ระหว่างแต่ละส่วนก่อนนำไปใช้เป็นแนวทางในการพัฒนาระบบ

### 7. เหตุผลในการใช้ AI:

เพื่อช่วยทำความเข้าใจ Flow การทำงานของรายงานยอดขาย และช่วยตรวจสอบความครบถ้วนของ Sequence Diagram ทำให้สามารถนำ Diagram ไปใช้เป็นแนวทางในการพัฒนาและตรวจสอบระบบได้ชัดเจนขึ้น

### 8. Diagram/เอกสารต้นทางของ Sprint นี้:

- `wk03-requirements.md` — Requirements Document
- `wk04-user-stories.md` — User Stories และ Acceptance Criteria
- `wk04-usecase.png` — Use Case Diagram ของกลุ่ม (หากใช้ในงานส่วนนี้)
- Sequence Diagram และ Business Rule จากสัปดาห์ที่ 9
- Sequence Diagram ของรายงานยอดขายที่จัดทำในสัปดาห์ที่ 10

### 9. ส่วนที่ AI ช่วยเขียนโค้ด:

- ช่วยแนะนำแนวทางการออกแบบลำดับการทำงานของระบบรายงานยอดขาย
- ช่วยตรวจสอบแนวคิดและองค์ประกอบของ Sequence Diagram

หมายเหตุ: หาก AI ไม่ได้ช่วยเขียนโค้ดในสัปดาห์นี้ ไม่ควรระบุว่า AI ช่วยเขียนโค้ดจริง แต่ให้ระบุเฉพาะการช่วยออกแบบหรืออธิบายตามที่เกิดขึ้นจริง

### 10. สมาชิกที่อธิบายโค้ดส่วนนี้ได้ (ต้องมีอย่างน้อย 1 คนต่อส่วน):

สมาชิกที่รับผิดชอบงานส่วนนี้ทบทวนและทำความเข้าใจ Flow รายงานยอดขาย รวมถึงสามารถอธิบายลำดับการทำงานและความสัมพันธ์ระหว่างองค์ประกอบใน Sequence Diagram ได้
