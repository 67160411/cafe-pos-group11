### 4. Prompt ที่ใช้ (ตัวอย่าง):

"ช่วยตรวจสอบโค้ด Backend ของ Cafe POS ว่ามีข้อผิดพลาดหรือไม่ และแนะนำวิธีแก้ไข"

"ช่วยวิเคราะห์ระบบ Cafe POS และแนะนำโครงสร้างฐานข้อมูลที่เหมาะสม พร้อมตรวจสอบความสัมพันธ์ระหว่าง Entity และการออกแบบตารางใน schema.sql"

### 5. ผลลัพธ์จาก AI:

AI ช่วยแนะนำการออกแบบฐานข้อมูลและความสัมพันธ์ระหว่าง Entity รวมถึงให้คำแนะนำเกี่ยวกับโครงสร้าง Backend, API และการเชื่อมต่อ MySQL นอกจากนี้ยังช่วยตรวจสอบโค้ด อธิบายสาเหตุของข้อผิดพลาด และเสนอแนวทางแก้ไขปัญหาที่พบระหว่างการพัฒนาและทดสอบระบบ

### 6. การปรับแต่งของตัวเอง:

นำคำแนะนำจาก AI มาพิจารณาและปรับให้เหมาะสมกับระบบ Cafe POS ของกลุ่ม โดยตรวจสอบความถูกต้องของโครงสร้างฐานข้อมูล ความสัมพันธ์ของข้อมูล และโค้ดก่อนนำไปใช้งานจริง รวมถึงปรับแก้รายละเอียดของระบบและโค้ดให้ตรงกับความต้องการของโจทย์และการออกแบบของกลุ่ม

### 7. เหตุผลในการใช้ AI:

ใช้ AI เพื่อช่วยตรวจสอบการออกแบบฐานข้อมูล และช่วยแก้ไขปัญหาทางเทคนิคระหว่างการพัฒนา ทำให้สามารถพัฒนาและตรวจสอบงานได้รวดเร็วขึ้น อีกทั้งช่วยให้เข้าใจเหตุผลและแนวทางในการพัฒนาระบบมากขึ้น
