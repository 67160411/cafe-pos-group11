## 2. องค์ประกอบของระบบเบื้องต้น

### People
- เจ้าของร้าน
- พนักงานหน้าร้าน
- บาริสต้า
- ลูกค้า
- ผู้ดูแลระบบ

### Process
- รับคำสั่งซื้อ (Order)
- คิดเงินและรับชำระเงิน
- พิมพ์ใบเสร็จ
- ส่งรายการให้บาริสต้าชงเครื่องดื่ม
- จัดการเมนูและอัปเดตสถานะคำสั่งซื้อ

### Data
- ข้อมูลเมนู
- ราคา
- รายการสั่งซื้อ
- ข้อมูลสต็อกวัตถุดิบ
- ข้อมูลพนักงาน
- รายงานยอดขาย

### Hardware
- เครื่อง POS
- คอมพิวเตอร์
- เครื่องพิมพ์ใบเสร็จ
- Database Server

### Software
- ระบบ POS
- ระบบจัดการสต็อก
- ระบบจัดการเมนู
- ระบบรายงานยอดขาย

### Network
- Internet
- Wi-Fi ภายในร้าน

## 3. แบบจำลอง SDLC ที่เลือกใช้

### Agile

**เหตุผล**

1. เจ้าของร้านและพนักงานสามารถทดลองใช้งานระบบในแต่ละเวอร์ชันได้อย่างรวดเร็ว ทำให้ได้รับข้อเสนอแนะตั้งแต่ช่วงแรกของการพัฒนา

2. สามารถปรับปรุงและแก้ไขระบบให้ตรงกับความต้องการของผู้ใช้งานได้อย่างยืดหยุ่น โดยไม่ต้องรอให้พัฒนาระบบทั้งหมดเสร็จสิ้น

3. ระบบสามารถพัฒนาเป็นส่วน ๆ (Increment) และส่งมอบฟังก์ชันที่ใช้งานได้จริงในแต่ละรอบ ช่วยลดความเสี่ยงและไม่จำเป็นต้องเริ่มพัฒนาใหม่ทั้งหมดเมื่อมีการเปลี่ยนแปลงความต้องการ
